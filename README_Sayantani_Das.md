# Agricultural Data Acquisition and Cleaning

## Week 1 -- Agricultural Data Analytics Project

### Project Overview

This project focuses on acquiring, inspecting, cleaning, and validating
agricultural crop production data using Python, Pandas, and SQL in
Google Colab.

The project uses the **Crop Production in India** dataset from Kaggle.
The objective is to transform raw agricultural data into a structured
and reliable dataset suitable for further analysis.

### Project Objectives

1.  Acquire agricultural data from a public dataset.
2.  Inspect the dataset structure and data types.
3.  Identify missing and duplicate records.
4.  Detect invalid and inconsistent values.
5.  Standardise column names and text fields.
6.  Convert numeric columns into appropriate data types.
7.  Separate invalid records for manual review.
8.  Generate a cleaned dataset.
9.  Validate the cleaned data using SQL queries.
10. Generate summary tables for agricultural analysis.

### Data Cleaning Workflow

1.  **Data acquisition:** Download the CSV dataset from Kaggle and
    upload it to Google Colab.
2.  **Data inspection:** Review dimensions, column names, data types,
    sample records and missing values.
3.  **Data cleaning:** Handle missing values, identify duplicates, trim
    whitespace, standardise text and validate numeric values.
4.  **SQL validation:** Use DuckDB SQL to profile data, flag invalid
    records, create clean and review tables, and validate the results.
5.  **Transformation:** Convert area and production to numeric values
    and calculate yield per area when area is greater than zero.
6.  **Export:** Save the clean data, review records and summary output.
